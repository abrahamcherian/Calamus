Calamus
A free, open-source text and code editor for macOS

This app costs nothing, has no subscription, and shows no ads. It's a
personal project, not a commercial product. (See About Calamus for
the version number.)

GETTING AROUND
- Files open as tabs in one window (native macOS tabs). Drag a tab out
  to give it its own window, or use Window > Merge All Windows to bring
  tabs back together.
- Window > Pin Tab keeps a saved file's tab pinned across relaunches:
  pin it once, and Calamus reopens it automatically every time you
  start the app. A pinned tab's file must be saved first.
- Window > Duplicate Tab opens a second, independent copy of the
  current tab's text, so you can branch off edits without touching the
  saved file.

WHERE TO LOOK
- Font, size, theme, background and text colors:  Font & Colors…   (⌘,)
- Every other setting (transparency, Insert and Random Generator
  defaults, and a Reset All Settings option):      Preferences…    (⌥⌘,)
- Comment or uncomment the selection:               Edit > Toggle Comment  (⌘/)
- Reformat, sort, reverse, or tabularize text:       Format > Text Formatting
- A Random Generator (passwords, UUIDs, filler text and more):  Insert menu
- Run the current file, or open a Terminal here:     Terminal menu
